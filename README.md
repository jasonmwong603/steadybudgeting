# Steady — budgeting / money tool

A simple, self-contained budgeting and money-smoothing tool. Single-page static
HTML, no build step, no backend — your data stays in your browser.

**Live:** https://jasonmwong603.github.io/steadybudgeting/

- `index.html` — the all-in-one tool (budget + set-aside + smoothing)
- `steady.html` — the daily-earnings / irregular-income view
- `budget.html` — the standalone monthly budget view

## Hosting
Deployed to GitHub Pages via `.github/workflows/pages.yml` on every push to
`main`. This project is intentionally **independent of keydate.ca** — it has no
custom domain and lives only at the github.io URL above.
